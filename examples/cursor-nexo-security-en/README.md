# Cursor × NEXO · Session 03 — Secure Code with Cursor (English)

English translation of the deck used for the third session of the
**Cursor × Fundación NEXO** LATAM webinar series, April 2026. Topic:
shipping secure code with Cursor (Cursor Rules, prompt-engineered review,
Semgrep MCP).

Speaker: Niccolò Mascaro · Cursor Ambassador · LATAM.

The original Spanish version lives in
[`examples/cursor-nexo-security/`](../cursor-nexo-security/). This
English translation is preserved as a reference for what a finished deck
looks like when this template is taken to production.

## Run it

```bash
# from the repo root — or cd into this folder and run any static server
npx serve . -l 4321
```
